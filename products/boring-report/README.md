Internal research artifact for DeFi / onchain finance boringness ratings.

- `SOURCES.md` — P0 source probe results
- `snapshots/2026-07-05/` — committed source payloads for the first weekly issue

- `verify.py` — fail-closed snapshot/report verifier
- `scorecard/` — P2 Oracle Scorecard v0: protocol fact files, SHA-256-verified source snapshots, deterministic Markdown/JSON/HTML renderer, and `verify_scorecard.py`
