# Morning Report Format

The daily 7am Commander loop must produce a brief Josh can scan from phone or GitHub in about 60 seconds.

## Required output

```text
🌅 COMMANDER MORNING BRIEF — YYYY-MM-DD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💰 TODAY'S MONEY MOVE
One sentence: highest-leverage safe action advanced or prepared.

✅ DONE WHILE YOU WERE AWAY
- 1–3 concrete bullets only.

👀 YOUR 60-SECOND REVIEW
- Open: one exact repo path or GitHub-readable artifact path.
- Decide: one copy/paste approval phrase, or “no decision needed.”

🚦 STATUS
- Waiting on Josh: one blocker or “none”.
- Safety: no posting / no sending / no spending / no secrets.
- GitHub: committed+pushed, or local-only with reason.

➡️ NEXT IF YOU DO NOTHING
One sentence describing the next safe draft-only/backstop action.
```

## Rules

- Under 60 lines.
- One recommendation, not a menu.
- Paths must be exact and easy to open from GitHub/Pi.
- Put approval phrases in copy/paste form.
- Keep long detail in `logs/daily_progress.md`, not the morning brief.
- If blocked on Josh, run the safest revenue backstop and say so.
