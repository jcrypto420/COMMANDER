# Bad Boys TikTok Posting / Scheduling SOP v0

Status: draft only. Do not post, upload, schedule, or spend without Josh approval.

## Purpose

Make posting repeatable once the rollout is approved.

## Principles

- Draft first, schedule second, publish last.
- Keep the first month simple.
- Use one weekly theme at a time.
- Never lose the pseudonymous safety boundary.

## Workflow

1. Fill the 7-day batch template.
2. Review the copy for tone and risk.
3. Attach the visual note for each post.
4. Put the posts in the right day order.
5. Prepare the approval packet.
6. Wait for Josh approval.
7. Schedule only after approval.
8. Log what was actually posted.
9. Review the weekly signal.
10. Choose the next week based on what hit.

## Scheduling rules

- post once per day during testing
- keep the same time window for a full week
- do not mix too many formats in one week
- do not change the account setup while testing unless needed for safety
- stop or pivot if the content starts reading generic

## Weekly review questions

- Which post got the strongest replies?
- Which post got the clearest saves/shares?
- Which caption caused the most comment energy?
- Which visual lane should stay?
- Which lane should die?

## Manual queue fields

- date
- day number
- caption
- visual brief
- CTA
- status: draft / approved / scheduled / posted
- notes
