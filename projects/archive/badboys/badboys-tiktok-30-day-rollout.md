# Bad Boys TikTok 30-Day Rollout v0

Status: draft only. Do not post, upload, schedule, or spend without Josh approval.

## Goal

Build a 30-day pseudonymous TikTok testing loop that compounds signal into the
next content and product decisions.

## Strategy

- Week 1: identity and slogan tests
- Week 2: mascot / Joycat / character tests
- Week 3: product seed and merch appetite tests
- Week 4: world-building and conversion tests

## Month rules

- one primary theme per week
- one short post per day
- batch the next week before the current week ends
- keep visuals coherent so signal is easy to read
- no public action without Josh approval

## Week 1 — Identity

Theme: "What is Bad Boys?"

Success signals:
- follows
- profile taps
- comments on the slogan
- saves/shares on the strongest post

Draft post lane:
- manifesto text cards
- OG face mark
- bold slogan lockups
- simple question CTAs

## Week 2 — Mascot / Joycat

Theme: "Who travels with the brand?"

Success signals:
- Joycat recognition
- comments about the character
- stronger replay value
- more conversational replies

Draft post lane:
- Joycat companion crops
- mascot reaction frames
- duo compositions
- playful character dialogue

## Week 3 — Product seed

Theme: "What would people actually buy or use?"

Success signals:
- sticker / PFP preference
- mockup saves
- product curiosity
- replies with use cases

Draft post lane:
- sticker pack concepts
- PFP pack mockups
- apparel/patch/pin concepts
- simple demand questions

## Week 4 — World-building

Theme: "What world should this become?"

Success signals:
- Roblox / badges / lore interest
- people suggesting formats
- stronger identity memory
- comments that point to the next expansion

Draft post lane:
- lore cards
- badge / icon concepts
- mini comic frames
- world-map style teaser art

## Daily template

1. caption
2. visual brief
3. CTA
4. posting note
5. approval note

## Weekly decision rule

At the end of each week:
- keep the top 2 hooks
- keep the top 1 visual lane
- cut the weakest 1-2 ideas
- write the next week from the winner

## Month-end decision rule

At day 30, choose one of:
- double down on the best slogan lane
- double down on the best character lane
- package the best outputs into a simple product offer
- pivot to a different visual format if signal is weak

## KPI snapshot

Track:
- follows per post
- comments per post
- saves/shares per post
- average watch signal if available
- which caption got the strongest reply quality

## Approval packet shape

Approval request: publish/test 30-day Bad Boys TikTok rollout
Why: generate signal before building larger products or scheduling long-term output
Risk: medium brand/platform risk; reduced by pseudonymous posting and no copied IP
Cost: $0
Account: pseudonymous TikTok only
Exact action: post only the approved daily batch items
