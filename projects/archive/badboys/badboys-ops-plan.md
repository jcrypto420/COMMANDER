# Bad Boys / Joycat / Mog Ops Plan v0

Status: draft only. No posting, sending, account creation, or spending without Josh approval.

## Purpose

Make the brand executable with one operating system for:
- content creation
- post scheduling
- long-term planning
- account setup prep
- approval checkpoints

## Execution stack

1. Brand standard
2. Weekly content calendar
3. Approval packet for any public action
4. Scheduling queue
5. Postmortem / learnings
6. Monthly planning refresh

## Fastest safe lane

Start with draft content and planning assets only:
- captions
- image prompts
- post order
- approvals
- metadata
- long-term roadmap

Do not create accounts or schedule public posts until Josh approves the exact target and platform.

## Working lanes

### 1) Content creation

Inputs:
- one theme
- one asset type
- one slogan or hook
- one CTA or engagement question

Output:
- post caption
- visual brief
- alt text / short description
- approval request text

### 2) Post scheduling

Draft schedule rules:
- one core post per day when testing
- keep the first week simple
- batch the content before any public publishing
- schedule only after the approved post packet exists

### 3) Long-term planning

Cadence:
- weekly: choose the next 7-day content batch
- monthly: decide the strongest lane to double down on
- quarterly: decide whether the brand should expand into merch, Roblox, or a productized pack

Planning questions:
- Which slogan gets the most replies?
- Which visual lane gets saves or shares?
- Which character lane should stay foregrounded?
- What is the smallest offer people would actually buy?

### 4) Account creation prep

This is prep only, not execution.

Recommended platform: TikTok first.

Need before creation:
- platform choice
- handle shortlist
- bio draft
- icon/avatar choice
- posting rules
- moderation rules
- recovery info stored safely by Josh
- approval to create the account

## Draft workflows

### Weekly content workflow

1. Pick the theme
2. Draft 3 post angles
3. Choose 1
4. Draft the visual brief
5. Write the approval packet
6. Queue the post after approval
7. Log results

### Monthly planning workflow

1. Review week performance
2. Note the best hook
3. Note the weakest hook
4. Keep what converts
5. Cut what feels generic
6. Plan the next batch

## Approval packets needed

- public posting packet
- account creation packet
- scheduling packet
- any paid tool or spend packet

Turn the week-one calendar into a reusable template for future weeks so content generation gets faster.
