# Bad Boys Mogging Tactics Playbook v0

Status: internal operating playbook. Do not post or message without approval.

## Definition

For Bad Boys, mogging means the artifact dominates the feed without explaining itself.

The viewer should think one of:
- I want that as a sticker.
- I want that as a PFP.
- I could wear that.
- What is this from?
- This is stupid but I am saving it.
- I need to vote because the choice is obvious.

## The anti-corn formula

Bad post:
- explains the mission
- asks people to join
- uses inspirational rebellion language
- talks like a founder

Mogging post:
- looks like an object
- gives the viewer a judgment job
- uses almost no caption
- creates status ambiguity
- makes people ask what it is

## Repeatable formats

### 1. BAD SAMPLE
Use for rough tests.

Template:
- BAD SAMPLE / 001
- object visual
- KEEP / KILL

### 2. FIELD TEST
Use for first exposure to a new asset.

Template:
- FIELD TEST
- one object
- caption: `field test 00X`

### 3. DROP CANDIDATE
Use for product-shaped posts.

Template:
- DROP CANDIDATE
- pfp/sticker/tee/mockup
- comment seed: `use it or trash it?`

### 4. WARNING LABEL
Use for identity posts.

Template:
- warning-label visual
- minimal phrase
- no explanation

### 5. CHARACTER SAMPLE
Use for Joycat/Bad Boys face.

Template:
- character/object
- `main or side problem?`

### 6. WORLD TEST
Use for Roblox/comic/toy lanes.

Template:
- three lanes
- `pick a lane`

## Caption bank: less corny

- `field test 001`
- `keep or kill`
- `drop candidate`
- `bad sample`
- `use it or trash it`
- `too clean / too cursed`
- `main problem or side quest`
- `no hype. pick one.`
- `sticker?`
- `pfp?`
- `would this survive the group chat?`
- `delete or make worse?`
- `needs less polish`
- `not explaining this`
- `if you know, you know`

## Banned copy

- `we are the noise`
- `join the movement`
- `be part of history`
- `building the future`
- `for the culture` unless used ironically/sparingly
- `for humanity` as a repeated caption
- long mission statements
- alpha/body-comparison mogging
- token/price language

## Metrics that matter

- comments that pick a lane
- saves
- shares
- profile visits
- people asking what it is
- people saying they would use/wear it
