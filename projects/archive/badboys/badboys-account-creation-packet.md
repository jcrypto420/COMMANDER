# Bad Boys / Joycat / Mog Account Creation Packet v0

Status: draft only. Do not create the account, post, or spend without Josh approval.

## Recommended platform

TikTok first.

Reason:
- strongest discovery engine for a new pseudonymous brand
- meme-native short-form works well with the brand voice
- good for testing slogans, mascot energy, and visual hooks quickly
- easy to repurpose the same content into Reels/Shorts later

## Account concept

Goal: a pseudonymous Bad Boys/Joycat/Mog account that tests hooks, characters, and simple visual systems.

## Profile image directions

Use one of:
- OG face mark
- clean text mark
- simple mascot crop

Avoid:
- busy poster art
- unreadable collage images
- anything that hides the core mark at thumbnail size
