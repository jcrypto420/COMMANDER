# Bad Boys / Joycat / Mog Launch Loop v0

Status: draft only. Do not post, send, publish, upload, or spend without Josh's
explicit approval.

## Goal

Build followers and sales around a pseudonymous, meme-native creative brand:

- "Moggers Mog"
- "Be Bad For Da Good of Humanity"

## Working hypothesis

The fastest safe path is not a full game first. It is an audience + offer loop:

1. Publish meme-native identity/content.
2. Test which character/phrase/visual angle gets engagement.
3. Package the strongest angle into a small sellable digital/merch/game-asset
   offer.
4. Repeat daily with low cost and tight feedback.

## First offer candidates

Ranked by speed and low cost:

1. Meme/brand digital pack: wallpapers, PFPs, banners, stickers.
2. Merch mockup set: shirts/stickers/posters, demand-tested before production.
3. Roblox/game asset concept pack: characters, props, badges, UI ideas.
4. Community membership/drop concept: only after audience signal.
5. Higher-touch brand/IP pack: only if inbound interest appears.
