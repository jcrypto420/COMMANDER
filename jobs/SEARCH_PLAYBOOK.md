# Job Search Playbook — ported from ChatGPT's operating system (2026-07-03)

Source: Josh's ChatGPT lane ("Job Search Operating System", July 2026), adopted as
the shared method for ALL agents. Tracker first: `jobs/TRACKER.md`.

## Positioning thesis (the story every application tells)

Not "generic operations analyst." The angle is: **institutional financial
operations + settlement/trade workflows + crypto/DeFi fluency + S&P-published
research** (oracles, crypto/AI; interoperability/tokenization pending Josh's
ruling — see TRACKER open items). Honest bridge, never overclaimed: institutional
settlement operations + crypto research + DeFi literacy — NOT direct
custody/trading-desk experience.

## Role clusters (search these, in priority order)

1. Crypto/digital-asset operations: settlement, custody ops, wallet ops, reconciliation, blockchain ops
2. Oracle / interoperability / data risk: data risk ops, oracle risk, market data ops, proof of reserve, cross-chain
3. Stablecoin / payments / tokenized cash: issuance, ops, partnerships, treasury solutions, payment rails
4. Tokenization / RWA: tokenized assets ops, capital-markets blockchain, onchain finance strategy
5. Market infrastructure / trading ops: prediction markets, post-trade, liquidity/market-maker relations
6. Brokerage / money movement: clearing & settlement, ACATS, funding rails, post-trade settlement
7. Institutional client operations: fiat/ACH ops, client service — digital assets

## Process (discovery → application)

1. **Discover** across clusters + company boards; aggregators (LinkedIn, Lensa, Built In, Web3.career) are LEADS only
2. **Verify at the official source** — Lever/Greenhouse/Ashby/Workday/company ATS. Ashby JSON trick: `POST jobs.ashbyhq.com/api/non-user-graphql` (worked for Chainlink 2026-07-03). Stale/no-official-page/fake-remote = reject
3. **Score 1-10:** fit story in 2-3 honest sentences? crypto-adjacent? genuinely remote? S&P research leverage? credible stretch?
   - 9-10 apply + tailor immediately · 7-8 apply if interested · 5-6 quick-apply/long shot · <5 skip
4. **Tailor only ≥7:** targeted resume, cover note, "why company," recruiter message, form answers → full packet in `jobs/packets/`
5. **Record in TRACKER.md same-day** — the non-negotiable step

## Cadence

- **Daily (morning loop):** quick scan Tier 1 boards; update TRACKER; flag ≥8 roles in the dispatch
- **2-3x/week (midday/evening lanes):** broader cluster searches; verify + score; draft packets for ≥7 roles (ARTIFACT RULE applies — a search pass with no tracker/packet output is a failed run)
- **Weekly (Monday review):** prune stale rows, rank live roles, report applications sent vs. drafted

## Rejection rules

Stale postings · aggregator-only listings · fake remote · title inflation (VP/Director as primary targets) · boring treasury/recon unless strategic · anything requiring dishonest experience claims

## Main rule

Search quality beats volume. The goal is roles where Josh's background sounds
*unusually* relevant — not the most applications.
